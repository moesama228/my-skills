# Productivity Skills

该分类收录跨项目使用的通用效率工具和元工作流。

## 可用技能

- [`markdown-document-export`](markdown-document-export/SKILL.md)：将 Markdown 导出为精美的 PDF 或 Word 文档，并保留 Mermaid、本地图片和样式。
- [`pdf-toc-links`](pdf-toc-links/SKILL.md)：为文本型或扫描型 PDF 添加侧边栏书签和可点击的目录页链接。
- [`skill-creator-portable`](skill-creator-portable/SKILL.md)：创建、更新和审查符合 Agent Skills 规范的可移植技能，并可选择生成 OpenAI 元数据适配层。
